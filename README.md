# **Dino Game (Chrome Dinosaur Clone)**

Una réplica del icónico juego del dinosaurio de Google Chrome, creado en **Python** con **Pygame**. ¡Salta y agáchate para esquivar obstáculos y alcanzar la puntuación más alta!

---

## ◇ **¿Cómo jugar?**

◆ Asegúrate de tener **Python 3.11+** instalado.  
◆ Instala la librería necesaria:  

   ```bash
   pip install pygame
   ```

◆ Clona este repositorio y entra en la carpeta del proyecto.  
◆ Ejecuta el juego:  

   ```bash
   python dino_game.py
   ```

---

## ◇ **Mecánicas del juego**

◆ Velocidad progresiva conforme aumenta el puntaje.  
◆ Obstáculos aleatorios.  
◆ Sistema de puntuación y **high score**.  
◆ Sonidos de salto y colisión.  
◆ Animaciones para correr, saltar, agacharse y morir.  

---

## ◇ **Tecnologías utilizadas**

◆ **Python**  
◆ **Pygame**
